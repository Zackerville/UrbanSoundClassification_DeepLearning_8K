# Urban Sound Classification on UrbanSound8K using Log-Mel Spectrogram and Deep Learning

## Project Overview

This project studies urban sound classification on the UrbanSound8K dataset using deep learning models based on log-Mel spectrogram representations.

## Project Structure

- data/
- docs/
- notebooks/
- src/
- outputs/
- report/
- slides/

## Planned Experiments

1. CNN + log-Mel spectrogram
2. ResNet18 + log-Mel spectrogram
3. ResNet18 + log-Mel spectrogram + augmentation

# Problem

Classify a short urban audio clip into one of 10 sound categories.

# Objectives

1. Build a preprocessing pipeline for audio.
2. Convert audio into log-Mel spectrograms.
3. Train a CNN baseline.
4. Train a ResNet18 model.
5. Study the effect of augmentation.

# Research Questions

1. How effective is the CNN baseline?
2. Does ResNet18 outperform the CNN baseline?
3. Does augmentation improve generalization?

2. ResNet18 + log-Mel
